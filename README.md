# Система управления документами и внутренней корреспонденцией

Облачная система для управления документами и внутренней корреспонденцией, 
развёрнутая в Docker-контейнерах с использованием кластерной архитектуры.

## Архитектура

Система состоит из 5 контейнеров:
- **nginx** — reverse proxy, точка входа (порт 80)
- **frontend** — статический веб-интерфейс (HTML/CSS/JS)
- **backend** — API на Node.js + Express (порт 3000)
- **postgres** — PostgreSQL 15 (база данных)
- **redis** — Redis 7 (хранение JWT-сессий)

## Функционал

- Регистрация и вход пользователей (JWT + Redis)
- Роли: администратор / обычный пользователь
- CRUD документов с полями: номер, тема, тип, статус, содержание, автор
- Типы документов: входящий, исходящий, внутренний
- Статусы: черновик, на согласовании, подписан, отклонён
- Фильтрация по типу и статусу
- Права доступа: редактировать/удалять могут только автор или админ
